# ZoneLify

## Beskrivning
ZoneLify är en fullstack-webbapplikation som hjälper distribuerade team att synkronisera sina mötestider över olika tidszoner. Med en enkel och intuitiv användargränssnitt kan användare lägga till teammedlemmar och deras tidszoner, visualisera bästa möjliga tid för gemensamma möten, och därmed underlätta effektiv kommunikation och samarbete oavsett geografisk spridning.

## Funktioner
- Lägg till och hantera teammedlemmars tidszoner
- Automatiserad beräkning av bästa mötestid som passar alla deltagare
- Responsiv design som fungerar lika bra på mobil och desktop
- Användarautentisering med JWT för säker inloggning
- Enkel API-design för framtida integrationer, t.ex. kalenderkopplingar

## Teknologier
- Frontend: React.js, React Router, Axios
- Backend: Python, Flask, Flask-JWT-Extended, Flask-CORS
- Databas: (valfri, t.ex. SQLite för enkel utveckling eller PostgreSQL i produktion)
